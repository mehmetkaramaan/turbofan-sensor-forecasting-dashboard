Method & controls

Forecasting task

Each model predicts next-cycle T50 from 17 variables over the preceding 30 cycles of the same engine. T50 is the low-pressure turbine outlet temperature, in °R. The six sensor cards show the observed engine state; the models use more than these six displayed channels.

MAE is mean absolute deviation. RMSE penalizes large deviations more strongly. Persistence repeats the latest T50 measurement. Lower errors are better. Scores refer only to the selected engine and revealed targets, so they can differ from the full-test results in the README.

What you can change and inspect

  1. Select 1-4 models. Compare their predictions of the same target and their individual residual plots.
  2. Move the cycle slider forward or backward. Errors are recomputed as measurements become available; future targets remain excluded.
  3. Switch the error interval between all history and the last 10/30/60 cycles to compare recent and cumulative performance.
  4. Change the engine and standardized sensor comparison. Stored model forecasts are available for engine 7; other engines display measurements.
  5. Playback speed affects presentation only. Full-trajectory view reveals observed measurements without adding future information to model inputs or metrics.

The input window is fixed at 30 cycles. Sensor measurements, model weights and hyperparameters are not edited here. A different input window, feature set or model configuration requires retraining in the notebook. This tool is not a physics-based engine simulator.

Interpretation & scientific scope

How to read this visualization

  1. At cycle t, only measurements observed up to that cycle are shown.
  2. The model uses the preceding 30 cycles to predict temperature at t+1. The star marks the next, unrevealed target forecast.
  3. Advancing one cycle reveals the measurement and updates the residual and cumulative metrics.

Scientific scope and limitations

This visualization replays FD001 measurements and computed model outputs. It does not solve internal temperature fields, thrust, or combustion physics. Combustor color is an illustrative accent; the T50 indicator represents the LPT outlet measurement.
